# HealthConnect Clinic Experience Lab

**Improving Patient Appointment Attendance and Healthcare Support Using Data and AI**

HealthConnect is a multidisciplinary healthcare project exploring how **data, machine learning and Generative AI** can reduce missed appointments and improve patient support.

### Week 4 — Project Management

Week 4 established the project's initial delivery baseline, including:

* Project Charter
* Scope Definition
* Work Breakdown Structure (WBS)
* Stakeholder Register
* Initial Risk & Dependency Register
* Communication Management Approach
* High-Level Delivery Roadmap

The project is structured around the following delivery logic:

**Business Need → Evidence → Solution → Operational Adoption → Measurable Value**

Project Management provides the integration layer across the technical and operational workstreams, with emphasis on **scope, dependencies, risks, stakeholder coordination, governance and delivery control**.
